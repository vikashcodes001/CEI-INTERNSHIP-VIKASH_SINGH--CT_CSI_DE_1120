# PySpark Data Processing Assignment

This repository contains a PySpark data pipeline for dataset cleaning, transformation, and regional salary aggregation.

## Project Structure

```
spark-assignment/
│── data/
│   └── dataset.csv
│── notebook/
│   └── spark_basics.ipynb
│── output/
│   └── results.csv
│── README.md
```

## Setup & Running

1. Install PySpark:
   ```bash
   pip install pyspark
   ```

2. Open the Jupyter Notebook:
   ```bash
   jupyter notebook notebook/spark_basics.ipynb
   ```

3. Execute the notebook cells sequentially to clean the dataset, apply transformations, and generate the final output.
